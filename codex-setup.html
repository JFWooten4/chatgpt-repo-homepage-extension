Set up Codex personalization

Install the local bridge once so Flawless ChatGPT can mirror your browser-side custom instructions into the Codex VS Code extension and import an optional PGP signing key without storing the private key in browser settings.

  1. Open Terminal in this extension's folder.
  2. Choose your browser and run the command below.
  3. Return to extension settings and use Sync to Codex.

      
The settings-only install does not require a research repository. If the research publisher is already linked, its repository configuration is preserved.
