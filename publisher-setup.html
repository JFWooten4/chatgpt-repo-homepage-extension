Link research repository

Choose a local Git repository once. The Add to repo button beside Download on each completed research report saves its Markdown, commits it, and pushes it to that repository’s origin remote and linked branch.

  1. Open Terminal in this extension’s folder.
  2. Run the command below, then choose your research repository folder.
  3. Enable Deep research publisher in extension settings and use Check connection to see the linked repository and branch.
  4. Refresh the ChatGPT report and click Add to repo, immediately left of Download.

      
Requires macOS, Python 3, Git, and working Git push access. The branch selected when you link the repository remains the destination until you link it again. Dashboard accounts do not change that destination.

      
Reports are published through a temporary checkout of the remote branch. Your local files, index, and branch are left untouched. No download or app picker is needed for each report.

      
If you previously linked an app, run this updated installer to link its repository folder instead. Re-run it after updating the bridge, moving the repository, or changing the extension ID. Turning the checkbox off removes the report buttons.
