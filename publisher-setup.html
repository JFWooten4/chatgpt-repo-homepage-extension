Link research publisher

Connect an installed macOS DOCX publishing app. The app converts your selected report to Markdown, then commits and pushes it to the repository configured by that app.

  1. Open Terminal in this extension’s folder.
  2. Run the command below, then choose your publishing app in the file picker.
  3. Return to extension settings, enable Deep research publisher, and click Open publisher….

      
Requires macOS and Python 3. Download your report as a DOCX before opening the publisher. Choosing a document in the app starts its conversion and publishing workflow. The destination and Git credentials come from the app, independently of the dashboard’s GitHub accounts.

      
The connection is local to this computer and extension ID. Run the installer again if you move the app or change the extension ID. Turning the checkbox off disables launching; it does not uninstall the connection.
